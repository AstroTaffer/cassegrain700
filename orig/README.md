# Код
- RFPINT3E.PAS – для наблюдений без фильтров
- RFBVRI4A.PAS – для наблюдений с фильтрами
- Файлы А, В и А2 – служебные, в них сохраняются начальные установки

На управляющем компьютере установлен DOS, используется CWSDPMI.EXE. Сборка
осуществляется с помощью Free Pascal 2.6.4 (dos264full). Я сконвертировал
оригинальные файлы с кодом из CP866 в UTF-8.

# Телескоп
> Фотометр имеет шесть каналов с фотоумножителями для двух звезд и фона неба.
> Можно проводить наблюдения без фильтров или со сменными фильтрами.
> Используется 8 управляемых компьютером шаговых двигателей.
> Шесть счетчиков импульсов (счет фотонов) передают отсчеты в компьютер.
> Для контроля и центрирования в диафрагмах фотометра невидимых для глаза звезд
> по их координатам используется самописец.
> Автоматическая гидирущая ПЗС-система исправляет неточности ведения телескопа.
> Компьютер контролирует состояние неба и при появлении плотных облаков по
> проводам передает звуковой сигнал на динамик.
